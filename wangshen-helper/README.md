# 网申助手

校招网申自动填写浏览器插件（Edge / Chrome）。把个人资料存一次，打开各家招聘网站的网申页面，点一下就把能识别的格子填好；也可以让 AI 助手通过网页内接口直接调用它。

> 只填写，不提交：登录、验证码、证件号和最后的“提交 / 投递”都由你自己完成。

## 能做什么

- **一键填写本页**：按标签文字识别字段，支持输入框、原生下拉框、各类组件库的下拉框和日期面板、单选 / 多选、省市联动、“添加一条”类的多条经历。
- **上传附件**：照片、简历等文件放进设置页，按“照片 / 简历 / 成绩单”等标签自动上传。
- **自定义问答**：各公司特有的题目，按“题目关键词 → 答案”填写。
- **下拉框备选写法**：`青岛|上海|*` 表示依次尝试“青岛”“上海”，都没有时选第一个选项。
- **诊断信息**：填完显示填了几项、哪些没填上，方便手动补。
- **给 AI 助手用的接口**：页面里的 `window.wszs.fill()`、`upload()`、`ping()`、`reload()` 会返回结构化结果，AI 助手可以直接调用并读取哪些字段失败了。
  - `wszs.set({ '学历': '本科', '教育经历>学校名称#2': '某某大学' })`：按标签直接给漏填的字段设值（下拉、日期、单选、联想框都走同一套点选逻辑），返回每项成功 / 失败。
  - `wszs.todo()`：重新检查还空着的必填项；填完后这些项会在页面上标橙色虚线框，并在结果的 `missingRequired` 里列出。

## 已适配的招聘系统

| 系统 | 支持情况 |
|---|---|
| 北森（zhiye.com 及定制域名） | 支持 |
| hotjob 电脑版（Wecruit） | 支持 |
| 前程无忧 51job（传统表格、wt 系统、CRMS） | 支持 |
| Ant Design / Element 等组件库做的自建系统 | 支持 |
| Moka 新版（sd- 组件） | 基本支持（下拉、联想选学校 / 专业、“添加专业全称”、省市区三级面板、日期面板） |
| layui 自建系统 | 基本支持（单选、下拉、laydate 日期） |
| 国聘 iguopin | 部分支持（展示页 + 分块编辑） |
| hotjob 移动版 | 暂不支持 |

插件只在 `manifest.json` 的 `host_permissions` 里列出的网站生效。要支持新网站，把域名同时加进 `host_permissions` 和 `content_scripts` 的 `matches`。

## 安装

1. 下载并解压，得到 `wangshen-helper` 文件夹。
2. 打开 `edge://extensions`（Chrome 是 `chrome://extensions`），打开“开发者模式”。
3. 点“加载解压缩的扩展”，选中 `wangshen-helper` 文件夹。
4. 点插件图标 → “设置”，填好个人资料并保存。

## 隐私

- 资料只保存在浏览器本地（`chrome.storage.local`），插件不向任何服务器发送数据。
- 身份证 / 证件号一律不自动填写（`wszs.set` 也不行），只能本人在网页上填；填完结果里会列在“本人填写”。
- 自带的 `profile.default.json` 是空白模板，不含任何真实个人信息。

## 注意

- 部分招聘平台的用户协议限制自动化操作，请自行判断，并在提交前逐项核对。
- 自动识别不可能 100% 准确，日期、下拉框和学校名称尤其要检查。
